处理逻辑

  1. 自适应轻抓：新来源/有效来源每周扫；长期低产出来源先降为低成本观察，极低产出且样本充分时降为月度探测。
  2. 先去重：URL + 标题近似，减少转载噪音。
  3. 已有知识比较：Knowledge + Work System 用来判断重复、知识空白、边界和证据增量。
  4. 深读候选：高潜力文章才尝试读正文；受 robots / 登录限制时明确标记。
  5. 滚动反馈：最近12周反馈影响当前排序和注意力预算；旧偏好不会永久锁死推荐。
  6. 冷热分层：最近90天保留完整 Weekly 数据，更旧文章转成轻量历史记录继续用于去重和学习记忆。
